# 經濟學導讀

經濟學只出現在 B 考第三節，跟管理學合考：六大題申論、120 分鐘、100 分，經濟學佔三題約 50 分。沒有選擇題、沒有填充，**每一題都要畫圖、要算**。這科和其他五科最不一樣：不是「認得名詞」，是「會操作模型」。所以這頁不列 90 個名詞，只講五個模型，五年 15 大題全部在裡面。

好消息是它們反覆考：AD-AS 三次、剩餘分析三次、稅負歸宿兩次，五年 15 題有 8 題落在三個模型上。

## 這科怎麼考

看 114 年的三題就知道套路：

- 「根據簡單凱因斯模型，a=200、MPS=0.4、I=300、G=100、T=50+0.2Y，求均衡所得、乘數」——**給數字要你算**。
- 「小國開放貿易後進口 X，政府可以課關稅 t 或補貼生產 s，請繪圖說明兩者的社會福利差異」——**要你畫圖比較**。
- 「一國處於長期均衡，央行大幅調降準備金利率，請以 AS-AD 模型繪圖分析短期與長期」——**畫圖推演**。

每題 15–18 分，答案要有：圖（軸、線、均衡點都標字母）、文字說明（每一步為什麼移動）、結論（價格、產量、福利怎麼變）。沒有圖大概拿一半分。

## 模型 1：供需與剩餘（個體，考最多）

一張圖：橫軸數量 Q、縱軸價格 P，需求線往下、供給線往上，交點是均衡。**消費者剩餘**是需求線以下、價格以上的三角形（願意付的減實際付的）；**生產者剩餘**是價格以下、供給線以上的三角形。兩個加起來是社會福利，任何干預（課稅、補貼、限價、關稅）都會讓它變小，少掉的那塊叫**無謂損失**。

**從量稅歸宿**：對每單位課 t 元的稅，供給線往上平移 t，新均衡價格上升但不到 t，剩下的由生產者吸收；誰吸收得多看**彈性**——彈性小的那一方（沒得選的）付得多。稅收是矩形、無謂損失是三角形，考題會要你把每一塊標出來。

這條線的考點：**個體 剩餘分析 消費者與生產者剩餘（3）**、**個體 租稅 從量稅歸宿（2）**、個體 需求彈性與稅負分配、個體 替代效果與所得效果、個體 消費者均衡 完全互補。

## 模型 2：市場結構——獨占與寡占

完全競爭廠商是價格接受者，P = MC 時利潤最大。**獨占**廠商面對整條需求線，多賣一單位要降全部的價，所以邊際收益 MR 低於價格（MR 線在需求線下方、斜率兩倍）；利潤最大在 MR = MC，價格定在需求線上，比競爭高、產量比競爭少。MR 拆成兩個效果：產量效果（多賣一個賺的）和價格效果（全部降價損失的）。

**寡占**的拗折需求曲線：「跟跌不跟漲」——我漲價別人不跟（需求線上半段很平，客人跑光），我降價別人跟（下半段很陡，搶不到多少）。需求線在現價處拗折，MR 線在那裡斷一截，所以成本小幅變動時 MC 在缺口裡移動、價格產量都不變——113 年考的就是這個。集中度用 CR4（前四大市占加總）和 HHI（每家市占平方和）衡量。

這條線的考點：個體 獨占 邊際收益 產量效果與價格效果、個體 寡占 拗折需求曲線、個體 市場結構 集中度 CR4 與 HHI、個體 利潤極大化 勞動雇用。

## 模型 3：簡單凱因斯模型（總體，要算）

總支出 AE = C + I + G，消費 C = a + b(Y − T)，b 是邊際消費傾向 MPC，MPS = 1 − b。均衡時 Y = AE，解出來就是均衡所得。**乘數**：政府多花 1 元，所得增加 1/(1−b)；有比例稅 T = T₀ + tY 時分母變成 1 − b(1−t)。114 年那題就是套這個。考法固定：先寫式子、代數字、解 Y、再算乘數，每一步寫出來，算錯數字也有部分分。

這條線的考點：總體 簡單凱因斯模型 均衡所得、總體 簡單凱因斯模型 乘數、總體 Cobb-Douglas 生產函數。

## 模型 4：AD-AS（總體，考最多）

橫軸實質產出 Y、縱軸物價 P。AD 往下（物價低大家買得多），短期 AS 往上，長期 AS 垂直（在充分就業產出）。三條線的交點是長期均衡。

考題永遠是「發生某件事，短期怎麼移、長期怎麼回來」：

- 疫情封鎖（113 年）：AD 左移（沒人消費）、AS 也左移（工廠停工）→ 產出大跌、物價看兩條線誰移得多；解封後 AD 大幅右移 → 物價上漲。
- 央行降息（114 年）：AD 右移 → 短期產出超過充分就業、物價上升 → 人們預期物價上漲、要求加薪 → 短期 AS 左移 → 長期回到垂直線，產出回原點、物價更高。「預期物價」就是短期 AS 線的位置，題目要你標出來。

畫這張圖的規矩：先畫長期均衡（三線交於一點 A），再畫衝擊後的短期均衡 B，再畫長期調整後的 C，三個點都標清楚，文字寫「從 A 到 B 是因為…，從 B 到 C 是因為…」。

貨幣數量說 MV = PY 是它的親戚：貨幣增加、速度不變、產出不變，物價等比例上漲。

這條線的考點：**總體 AD-AS 模型（3）**、總體 貨幣政策 準備金利率、總體 貨幣數量說 MV=PY。

## 模型 5：國際貿易與匯率

還是供需圖，多一條水平的「世界價格」線。**小國**接受世界價格：開放後若世界價格低於國內均衡，就進口，消費者剩餘大增、生產者剩餘減少、總福利增加。政府想保護國內生產有兩招：**關稅**（世界價格線往上抬 t，國內產量增、消費減，政府有稅收，但有兩個無謂損失三角形）和**生產補貼**（只推供給線，不動消費者，所以只有一個無謂損失三角形）——114 年考「同樣國內產量下，補貼的社會成本比關稅低」，就是少一個三角形。出口禁令、出口補貼是同一張圖反過來畫。

匯率：**購買力平價**說匯率會調整到兩國物價相等，實質匯率 = 名目匯率 × 外國物價 / 本國物價；通膨高的國家貨幣長期會貶。

這條線的考點：國貿 關稅與生產補貼、國貿 小國貿易 補貼政策、國貿 小國貿易 出口禁令、國際金融 購買力平價 實質匯率、國際金融 匯率與通膨成長。

## 怎麼用這頁

1. 這科不能只讀，要動手。五個模型每個畫十遍，畫到不看書能畫出來、每條線的名字和方向都對。
2. 考場的「手寫卷」開 B 考第三節，勾「用紙筆寫，這裡只計時」，真的畫在紙上，拍照丟給 Claude 批改，說「依配分評分，指出圖哪裡標錯」。
3. 順序：模型 1 → 4 → 3 → 5 → 2。前三個佔了考題一半以上。
4. 這科是 B 考專屬，A 考不考。如果時間只夠準備一場，它是最後才碰的一科；但如果要考 B，它是最容易靠練習拉分的一科，因為題型五年沒變過。
