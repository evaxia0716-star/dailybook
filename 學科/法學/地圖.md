# 法學地圖

A 考叫「法律常識」（約 25 題單選，偏憲法、行政法、勞動與生活法律常識），B 考叫「法學緒論」（獨立一科，範圍更廣，含法學基本理論、民法、刑法）。標〔A〕的是 A 考特別愛出、標〔B〕的是 B 考才會深入。

## 一、法學基本概念〔B 為主〕

- [ ] 法律的定義與特性；法律與道德、習慣、宗教的區別
- [ ] 法源：成文法（憲法、法律、命令、自治法規、條約）與不成文法（習慣、法理、判例、解釋）
- [ ] 法律的位階：憲法 > 法律 > 命令；法律優位、法律保留〔A〕
- [ ] 法律的分類：公法／私法、實體法／程序法、普通法／特別法、強行法／任意法
- [ ] 法律的效力：時（不溯及既往、施行日）、人、地、事
- [ ] 法律的制定與修正程序；三讀；公布與生效（總統公布後第三日）
- [ ] 法律的適用原則：特別法優於普通法、後法優於前法、從新從優
- [ ] 法律解釋：文義、體系、歷史、目的、合憲性；類推適用與反面解釋
- [ ] 法律關係：權利、義務；權利的分類（公權／私權、支配權、請求權、形成權、抗辯權）
- [ ] 法律責任：民事、刑事、行政責任的區別

## 二、憲法

- [ ] 憲法的意義、特性、種類；我國憲法沿革與增修條文
- [ ] 憲法前言與總綱：國體、主權、國民、領土、民族、國旗
- [ ] 基本權利：平等權、自由權（人身、居住遷徙、言論、秘密通訊、信仰、集會結社）、受益權、參政權
- [ ] 基本權利的限制：第 23 條比例原則、法律保留
- [ ] 人民的義務：納稅、服兵役、受國民教育
- [ ] 中央政府體制：總統、行政院、立法院、司法院、考試院、監察院之職權〔A〕
- [ ] 選舉方法：普通、平等、直接、無記名〔A〕
- [ ] 司法院職權：解釋憲法、統一解釋法令、審判、公務員懲戒；憲法法庭與憲法訴訟法
- [ ] 地方制度基本概念；基本國策

## 三、行政法〔A 為主〕

- [ ] 行政法的一般原則：依法行政、明確性、平等、比例、誠信、信賴保護、不當聯結禁止
- [ ] 行政組織：行政機關、公營事業、公法人、行政法人
- [ ] 行政行為的種類：行政處分、行政契約、法規命令、行政規則、行政指導、事實行為
- [ ] 行政程序法重點：管轄、當事人、期日期間、送達、聽證、資訊公開、陳情（第 168 條）
- [ ] 行政處分：定義、效力、附款、無效與撤銷、廢止
- [ ] 公法上請求權時效：人民 10 年、行政機關 5 年（第 131 條）
- [ ] 行政罰法：處罰法定、一行為不二罰、責任能力、裁處權時效 3 年、警告性處分種類
- [ ] 行政執行法：公法上金錢給付、行為或不行為義務、即時強制
- [ ] 行政救濟：訴願（30 日內、決定種類：不受理、無理由、有理由）→ 行政訴訟（撤銷、課予義務、確認、一般給付）
- [ ] 國家賠償：公務員違法侵害、公共設施設置管理欠缺；請求程序
- [ ] 公務員法：公務員服務法（忠實、保密、迴避、旋轉門）、公務人員保障法（復審、申訴）

## 四、民法

- [ ] 民法五編架構：總則、債、物權、親屬、繼承
- [ ] 總則：權利能力（始於出生終於死亡）、行為能力（無、限制、完全；7 歲、18 歲）、法人
- [ ] 意思表示：錯誤、詐欺、脅迫、通謀虛偽；法律行為的無效、得撤銷、效力未定
- [ ] 消滅時效：一般 15 年、5 年、2 年；時效中斷與不完成
- [ ] 債：契約成立（要約承諾）、債務不履行（給付不能、遲延、不完全給付）、侵權行為要件、不當得利
- [ ] 常見契約：買賣、租賃、借貸、僱傭、承攬、委任、保證
- [ ] 物權：所有權、共有、抵押權、質權、地上權；動產交付、不動產登記；善意取得
- [ ] 親屬：結婚要件（書面、二人證人、登記）、離婚、夫妻財產制、親權、扶養
- [ ] 繼承：繼承順序（直系血親卑親屬 → 父母 → 兄弟姊妹 → 祖父母）、應繼分、特留分、限定繼承、拋棄繼承 3 個月
- [ ] 消費者保護法：定型化契約、郵購 7 日解除、商品責任〔A〕

## 五、刑法〔B 為主〕

- [ ] 刑法的基本原則：罪刑法定、從舊從輕、屬地為主
- [ ] 犯罪三階段：構成要件該當、違法性、有責性
- [ ] 故意與過失；作為與不作為；因果關係
- [ ] 阻卻違法事由：正當防衛、緊急避難、依法令行為、業務正當行為
- [ ] 責任能力：14 歲、18 歲、80 歲；精神障礙
- [ ] 未遂、預備、中止犯；共同正犯、教唆犯、幫助犯
- [ ] 刑罰種類：主刑（死刑、無期、有期、拘役、罰金）與從刑；緩刑、假釋、累犯
- [ ] 常見罪名：殺人、傷害、竊盜、詐欺、侵占、背信、公然侮辱、誹謗、瀆職、貪污治罪
- [ ] 告訴乃論 vs. 非告訴乃論；追訴權時效

## 六、勞動與社會法〔A〕

- [ ] 勞動基準法：工時（每日 8、每週 40）、加班上限與加班費、休息日、例假、特別休假、最低工資
- [ ] 勞基法：資遣（預告期、資遣費）、解僱事由、退休金（新舊制）、職業災害補償
- [ ] 性別平等工作法：產假、陪產假、育嬰留停、性騷擾防治
- [ ] 勞工保險、就業保險、全民健康保險、國民年金基本概念
- [ ] 工會法、團體協約法、勞資爭議處理法基本概念
- [ ] 職業安全衛生法基本概念

## 七、生活法律常識〔A〕

- [ ] 個人資料保護法：個資定義、蒐集處理利用原則、當事人權利
- [ ] 著作權法：保護期間（終身＋50 年）、合理使用、公開傳輸
- [ ] 公司法基本概念：公司種類、董事會、股東會
- [ ] 票據法：支票、本票、匯票的差別
- [ ] 政府採購法基本概念：招標方式（公開、選擇性、限制性）、決標原則
- [ ] 公職人員利益衝突迴避法、政治獻金法基本概念
- [ ] 道路交通、環境保護常見罰則的常識題
