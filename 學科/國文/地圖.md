# 國文地圖

A 考只考作文一篇（100 分）。B 考通常是選擇題（約 20 題）＋作文，選擇題偏字音字形、成語、文意理解、應用文。作文兩場都有，所以寫作是這科的主幹。

## 一、作文：架構

- [ ] 審題：抓題目的關鍵字，判斷是「兩個概念的關係」還是「單一主題的闡述」
- [ ] 立意：一句話講完全篇主張；避免騎牆
- [ ] 四段架構：點題表態 → 舉例支持 → 反面或轉折 → 收回題目
- [ ] 各段字數配置：600～800 字，每段 150～200
- [ ] 段落的第一句要能獨立成立（主題句）

## 二、作文：開頭與結尾

- [ ] 開頭三招：定義法、對比法、場景法
- [ ] 名言法的風險：引錯扣分，沒把握不用
- [ ] 結尾：呼應開頭、把個人例子拉回普遍意義、一句有力的收束
- [ ] 避免「總之」「綜上所述」這類套語

## 三、作文：素材庫

- [ ] 自己的經驗 3 則（工作、學習、生活）可以套用在多種題目
- [ ] 公共人物或歷史例 5 則，每則記「人、事、可以支撐什麼主張」
- [ ] 抽象題常見組合：理想與現實、堅持與放棄、獨處與群體、傳統與創新、自由與責任
- [ ] 每題準備正反兩面各一個例子

## 四、作文：語言

- [ ] 常用成語 30 個，分「形容努力」「形容困境」「形容態度」三組
- [ ] 句型變化：長短句交錯、排比、設問
- [ ] 避雷：錯字、口語（「超」「蠻」）、網路用語、簡體字
- [ ] 20 分鐘寫完 600 字的節奏：審題 2 分、大綱 3 分、正文 13 分、檢查 2 分

## 五、選擇題：字詞〔B〕

- [ ] 常考錯別字與形近字
- [ ] 一字多音、破音字
- [ ] 成語的正確用法與常見誤用（望文生義）
- [ ] 詞語的褒貶與語境

## 六、選擇題：文意與閱讀〔B〕

- [ ] 白話短文的主旨判讀
- [ ] 文言短文：常見虛詞（之、其、以、而、於）與句型
- [ ] 修辭：譬喻、轉化、映襯、借代、排比、層遞、設問
- [ ] 古文常識：作者與作品配對、文體（記、說、論、序、賦）

## 七、選擇題：應用文〔B〕

- [ ] 書信：稱謂、提稱語、啟事敬辭、結尾敬辭
- [ ] 公文：函、公告、簽的格式；「主旨、說明、辦法」三段式
- [ ] 題辭、對聯、柬帖的場合用語
- [ ] 節氣、年齡稱謂、謙敬詞
