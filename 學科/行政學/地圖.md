# 行政學地圖

只有 A 考考這科（叫「行政學概要」，與法律常識同一卷，約 25 題單選）。它和管理學有一半是親戚：組織、激勵、領導、決策都重疊，先讀管理學地圖再讀這裡，重複的地方只要記「行政學的講法有什麼不同」。

## 一、行政學的基礎

- [ ] 公共行政的定義；政治／行政二分（威爾遜、古德諾）
- [ ] 行政與企業管理的異同：公共性、法令限制、績效衡量困難、獨占
- [ ] 行政學發展階段：傳統理論（1887–1930）、修正理論（1930–1960）、整合理論（1960–）
- [ ] 新公共行政（1968 明諾布魯克會議）：社會公平、民主行政
- [ ] 新公共管理（1980s）：市場機制、顧客導向、企業型政府（奧斯本與蓋伯勒「新政府運動」十原則）
- [ ] 新公共服務（丹哈特）：服務而非導航、公民而非顧客
- [ ] 治理、網絡治理、公私協力 PPP、黑堡宣言

## 二、組織理論

- [ ] 傳統理論：泰勒、費堯、古立克 POSDCORB、韋伯官僚體制特徵與病象
- [ ] 修正理論：霍桑實驗、巴納德、賽蒙行政行為、麥克葛羅格 X／Y
- [ ] 整合理論：系統理論、權變理論、生態理論（雷格斯稜柱模式）
- [ ] 組織結構：層級節制、分部化、幅度、集權分權；首長制 vs. 委員制
- [ ] 業務部門與幕僚部門；矩陣組織、專案組織
- [ ] 明茲伯格：五種協調機制、五個組織部分、五種構型
- [ ] 非正式組織：功能、反功能；達爾頓五種類型（垂直共棲、垂直寄生、水平防守、水平攻擊、隨機）
- [ ] 組織病象：白京生定律、彼得原理、寡頭鐵律、墨菲定律、邁爾斯定律、不希罕效應
- [ ] 組織氣候、組織文化（雪恩三層次）；學習型組織五項修練
- [ ] 組織發展與變革；組織衝突與管理

## 三、人事行政

- [ ] 人事制度：品位分類 vs. 職位分類；官僚制、恩寵制、功績制（潘德頓法）
- [ ] 公務人員考試、任用、陞遷、考績、俸給、保障、退休基本概念
- [ ] 人力資源管理與傳統人事行政的差別
- [ ] 訓練與發展；工作設計
- [ ] 公務倫理：行政中立、利益衝突迴避、旋轉門、吹哨者保護
- [ ] 代表性文官、多元管理、玻璃天花板

## 四、激勵、領導與溝通

- [ ] 激勵：內容論（馬斯洛、阿特福 ERG、赫茲伯格、麥克里蘭）與過程論（期望、公平、目標設定、增強）
- [ ] 唐斯五種官僚人格：爬升者、保守者、狂熱者、倡導者、政治家
- [ ] 領導理論：特質、行為（俄亥俄、密西根、管理方格）、權變（費德勒、路徑目標、情境領導）
- [ ] 李克特四系統、李文—懷特—李彼特三分法（獨裁、民主、放任）
- [ ] 轉換型領導、交易型領導、魅力領導、僕人領導
- [ ] 權力基礎（傅蘭琪與雷芬）；影響力策略
- [ ] 溝通程序、障礙、正式與非正式溝通；行政溝通的特殊性

## 五、行政決策與政策

- [ ] 決策模式：廣博理性、有限理性（滿意）、漸進（林布隆）、混合掃描（艾賽尼）、垃圾桶（柯恩、馬區、歐爾森）、政治性
- [ ] 政策過程階段：問題認定 → 議程設定 → 規劃 → 合法化 → 執行 → 評估
- [ ] 政策類型（羅威）：分配、管制、重分配、自我管制
- [ ] 政策工具；政策執行模式（由上而下、由下而上）
- [ ] 政策評估類型；政策終結；政策行銷
- [ ] 公民參與、審議式民主、鄰避效應 NIMBY

## 六、財務行政

- [ ] 預算的意義與功能；預算原則
- [ ] 預算制度演進：項目預算、績效預算、設計計畫預算 PPBS、零基預算 ZBB、目標管理預算
- [ ] 預算程序四階段：籌編、審議、執行、決算（審計）
- [ ] 公共財、外部性、政府失靈與市場失靈
- [ ] 公債、財政赤字、財政紀律

## 七、行政運作與管理技術

- [ ] 危機管理與風險管理
- [ ] 知識管理、組織學習

## 八、行政責任與控制

- [ ] 內部控制：層級節制、行政倫理、公務人員行為規範
- [ ] 外部控制：立法監督、司法審查、監察、媒體、公民
- [ ] 吉伯特行政責任四途徑：內部正式、內部非正式、外部正式、外部非正式
