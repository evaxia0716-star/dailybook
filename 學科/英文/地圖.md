# 英文地圖

兩場都是單選（A 考 40 題，B 考約 20 題），題型：字彙、文法、克漏字、閱讀測驗。已知弱點是詞性和固定搭配，所以第二、三章要最先勾完。

## 一、字彙

- [ ] 考古題出現過的單字整理成一頁，每字記「詞性＋一個例句」
- [ ] 常考字根字首：re-、pre-、un-、dis-、-tion、-able、-ment
- [ ] 易混淆字組：affect／effect、adapt／adopt、rise／raise、lie／lay
- [ ] 商務與辦公室情境字：procurement、approval、committee、statement、personnel

## 二、詞性與句子結構

- [ ] 五大句型：S+V、S+V+O、S+V+C、S+V+O+O、S+V+O+C
- [ ] 名詞、動詞、形容詞、副詞在句中的位置；形容詞放名詞前、副詞修飾動詞
- [ ] 主詞與動詞一致：單複數、集合名詞、there is／are、every／each
- [ ] 動詞後接不定詞（want、decide、plan）vs. 動名詞（enjoy、avoid、finish、mind）
- [ ] 介系詞後面一律接名詞或動名詞
- [ ] 連接詞 vs. 介系詞：because／because of、although／despite、while／during

## 三、固定搭配與介系詞

- [ ] 動詞＋介系詞：comply with、rely on、depend on、consist of、result in／from、apply for、care for
- [ ] 形容詞＋介系詞：responsible for、familiar with、interested in、capable of、aware of
- [ ] 名詞＋介系詞：reason for、solution to、access to、impact on
- [ ] 片語動詞：come up with、put up with、cut down on、look forward to、carry out、turn down
- [ ] submit to（交給誰）vs. submit for（為了什麼）

## 四、時態與語態

- [ ] 現在簡單（習慣、事實）、現在進行、現在完成（到現在為止）
- [ ] 過去簡單 vs. 過去完成（兩件過去事的先後）
- [ ] 未來式：will、be going to、現在進行表未來
- [ ] 時間副詞與時態的配對：last year → 過去、since → 完成、by the time → 完成
- [ ] 被動語態：be + p.p.；哪些動詞不能被動

## 五、子句與特殊結構

- [ ] 關係代名詞：who、which、that、whose、whom；the title of which
- [ ] 關係副詞：where、when、why
- [ ] 名詞子句：that、whether／if、疑問詞
- [ ] 假設語氣：與現在事實相反（were、would）、與過去事實相反（had p.p.、would have p.p.）
- [ ] 分詞構句、獨立分詞
- [ ] 比較級與最高級：as…as、the more…the more、比較對象一致

## 六、克漏字與閱讀

- [ ] 克漏字：先看整段找轉折詞（however、therefore、in addition）
- [ ] 閱讀：先看題目再讀文章；主旨題、細節題、推論題、字義題
- [ ] 常見文章類型：公告、電子郵件、廣告、新聞短訊、說明書
- [ ] 每週一篇閱讀，記錄答對率
