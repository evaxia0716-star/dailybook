# 經濟學考點

B 考經濟學申論（110–114）依考點分類。都是申論，重點是模型要會畫、會推。

共 20 個考點、25 題次。每張卡下面的「開這張概念卡」會直接在概念頁開一張同名的卡，內容想怎麼寫就怎麼寫；寫過的會變成連結。

## 【經】個體 剩餘分析 消費者與生產者剩餘

**考過**：3 次（B 考） · 110、114

- B110-五 表格算稅前稅後剩餘 → 稅前P=10、Q=30；稅後Q=20，買13賣7，稅收120
- B110-六 出口禁令與補貼的福利比較 → 國內均衡P=15；國際價高於15禁令才有效，價跌、總剩餘減
- B114-五 同產量下關稅與補貼的福利比較 → 關稅多一塊消費扭曲損失；補貼只扭曲生產但需財政支出

**概念卡**：（還沒寫）
