# 經濟學地圖

只有 B 考考這科（與管理學同一卷）。範圍是大一經濟學：前半個體、後半總體。這科最忌只背名詞，每個概念都要能畫圖或舉生活例子。

## 一、經濟學基本概念

- [ ] 稀少性、選擇、機會成本；生產可能曲線 PPC
- [ ] 實證 vs. 規範經濟學；個體 vs. 總體
- [ ] 經濟體系：市場經濟、計畫經濟、混合經濟；看不見的手
- [ ] 比較利益與絕對利益；專業化與交易
- [ ] 邊際分析、理性選擇、誘因

## 二、供給與需求

- [ ] 需求法則、需求曲線移動 vs. 沿線移動；影響需求的因素（所得、相關品價格、偏好、預期、人數）
- [ ] 正常財、劣等財；替代品、互補品
- [ ] 供給法則與影響因素（成本、技術、預期、家數）
- [ ] 市場均衡；超額供給、超額需求；均衡的變動
- [ ] 價格管制：價格上限（短缺）、價格下限（過剩，如最低工資）
- [ ] 稅的歸宿；補貼
- [ ] 消費者剩餘、生產者剩餘、無謂損失

## 三、彈性

- [ ] 需求價格彈性：定義、計算（中點法）、決定因素
- [ ] 彈性與總收益的關係
- [ ] 所得彈性（正常財、劣等財、奢侈品）、交叉彈性（替代、互補）
- [ ] 供給彈性與時間長短

## 四、消費者行為

- [ ] 效用、總效用、邊際效用；邊際效用遞減
- [ ] 消費者均衡：邊際效用均等法則（MU/P 相等）
- [ ] 無異曲線、預算線、最適選擇
- [ ] 所得效果與替代效果；季芬財、炫耀財
- [ ] 鑽石與水的矛盾

## 五、生產與成本

- [ ] 生產函數；短期 vs. 長期；總產量、平均產量、邊際產量；邊際報酬遞減
- [ ] 成本概念：機會成本、會計成本、經濟成本；固定、變動、總成本、平均、邊際
- [ ] 短期成本曲線關係（MC 穿過 AVC、AC 最低點）
- [ ] 長期平均成本、規模經濟、規模不經濟、規模報酬
- [ ] 沉沒成本；利潤最大化條件 MR = MC

## 六、市場結構

- [ ] 完全競爭：特徵、短期均衡、長期均衡（零經濟利潤）、停業點
- [ ] 獨占：成因（自然獨占、法律、資源）、定價、無謂損失、差別取價
- [ ] 獨占性競爭：產品差異化、長期零利潤但有超額產能
- [ ] 寡占：拗折需求曲線、卡特爾、賽局理論（囚犯困境、奈許均衡）
- [ ] 四種市場比較表：廠商數、產品、進入障礙、定價能力

## 七、要素市場與所得分配

- [ ] 勞動需求（邊際產值 MRP）、勞動供給（後彎）、工資決定
- [ ] 地租、利息、利潤的決定
- [ ] 所得分配：羅倫茲曲線、吉尼係數
- [ ] 貧窮線、所得重分配政策

## 八、市場失靈與政府

- [ ] 外部性：負（污染）與正（教育）；矯正方法（皮古稅、補貼、寇斯定理、排放權交易）
- [ ] 公共財：非排他、非敵對；搭便車問題
- [ ] 共有資源與共有地悲劇
- [ ] 資訊不對稱：逆選擇、道德風險、訊號、篩選
- [ ] 政府失靈

## 九、國民所得

- [ ] GDP 定義、三種計算法（支出、所得、生產）；GDP = C + I + G + (X − M)
- [ ] 名目 vs. 實質 GDP；GDP 平減指數；GDP 的限制
- [ ] GNP／GNI、NDP、NI、PI、DI 的關係
- [ ] 經濟成長率；人均 GDP
- [ ] 物價指數：CPI、PPI；通貨膨脹率計算

## 十、失業與通貨膨脹

- [ ] 勞動力、失業率、勞動參與率的定義與計算
- [ ] 失業類型：摩擦性、結構性、循環性；自然失業率、充分就業
- [ ] 通貨膨脹類型：需求拉動、成本推動、停滯性通膨；預期與非預期通膨的影響
- [ ] 菲力普曲線：短期取捨、長期垂直
- [ ] 痛苦指數 = 通膨率 + 失業率

## 十一、總供需與景氣循環

- [ ] 總需求曲線 AD 與移動因素；總供給 AS（短期、長期）
- [ ] 總體均衡；需求面衝擊與供給面衝擊
- [ ] 景氣循環四階段：擴張、高峰、收縮、谷底；領先、同時、落後指標
- [ ] 凱因斯簡單模型：消費函數、邊際消費傾向、乘數效果
- [ ] 古典學派 vs. 凱因斯學派的基本主張

## 十二、貨幣與銀行

- [ ] 貨幣的功能（交易媒介、價值儲藏、計價單位）與種類；貨幣供給 M1A、M1B、M2
- [ ] 銀行體系與貨幣創造：法定準備率、貨幣乘數
- [ ] 中央銀行的角色；貨幣政策工具：公開市場操作、重貼現率、法定準備率
- [ ] 貨幣需求；利率的決定；貨幣數量說 MV = PY
- [ ] 通膨與利率：費雪方程式（名目＝實質＋預期通膨）

## 十三、財政政策

- [ ] 政府支出與稅收；擴張性 vs. 緊縮性財政政策
- [ ] 自動穩定機制；乘數與排擠效果
- [ ] 預算赤字與公債；李嘉圖等值
- [ ] 財政政策與貨幣政策的搭配；政策時間落後

## 十四、國際經濟

- [ ] 比較利益與貿易利得；貿易障礙（關稅、配額）及其影響
- [ ] 國際收支：經常帳、金融帳、準備資產
- [ ] 匯率：直接／間接報價、升值與貶值的影響、購買力平價
- [ ] 匯率制度：固定、浮動、管理浮動
- [ ] 區域經濟整合層次：自由貿易區、關稅同盟、共同市場、經濟同盟；WTO
