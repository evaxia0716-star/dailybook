# 管理學地圖

這是這一科的骨架：每個 `##` 是一個母概念（章），底下的方格是子概念。讀懂一項就打勾，勾到哪裡看得見。〔A〕〔B〕標的是哪場考試會考；沒標的兩場都考。

用法：看到考古題出現某個名詞，先回來這裡找它的位置，把同一章的兄弟姊妹一起看完，再回去做題。這樣不會只記一個點。

A 考把這科叫「企業管理概論」（填充＋問答），B 考拆成「企業概論」與「管理學」兩科。

## 一、管理與管理者

- [ ] 管理的定義：效率（把事做對）與效能（做對的事）
- [ ] 管理四大功能：規劃、組織、領導、控制
- [ ] 明茲伯格管理者三大角色：人際、資訊、決策（共 10 個角色）
- [ ] 卡茲三種管理技能：技術、人際、概念；不同層級比重不同
- [ ] 管理層級：高階、中階、基層；控制幅度與組織層級
- [ ] 管理是科學也是藝術；管理者 vs. 領導者

## 二、管理思想演進

- [ ] 古典學派：泰勒科學管理（動作研究、差別計件）、吉爾布雷斯夫婦、甘特圖
- [ ] 費堯 14 項管理原則、五大功能；韋伯理想型官僚組織
- [ ] 行為學派：霍桑實驗（梅堯）、人群關係運動
- [ ] 巴納德合作系統、權威接受論；傅麗德
- [ ] 計量學派：作業研究、管理科學
- [ ] 系統學派：開放系統、投入—轉換—產出、綜效、熵
- [ ] 權變學派：沒有最好的方法，看情境
- [ ] 現代議題：全面品質管理（戴明 PDCA）、學習型組織（聖吉）、Z 理論（大內）

## 三、環境與文化

- [ ] 總體環境 PESTEL：政治、經濟、社會、科技、環境、法律
- [ ] 任務環境：顧客、供應商、競爭者、壓力團體
- [ ] 環境不確定性：變動程度 × 複雜程度
- [ ] 組織文化：定義、來源、七構面、強勢文化、傳遞方式（故事、儀式、符號、語言）
- [ ] 利害關係人管理
- [ ] 全球化：多國、跨國、無國界組織；霍夫斯泰德文化構面

## 四、社會責任與倫理

- [ ] 社會責任的四層次（卡羅爾金字塔）：經濟、法律、倫理、慈善
- [ ] 古典觀 vs. 社經觀；社會義務、社會回應、社會責任
- [ ] 企業社會責任 CSR、共享價值、ESG、綠色管理
- [ ] 倫理發展階段（柯爾伯格）、倫理決策因素、倫理守則
- [ ] 吹哨者、社會企業

## 五、決策

- [ ] 決策八步驟：確認問題 → 決策準則 → 權重 → 方案 → 分析 → 選擇 → 執行 → 評估
- [ ] 理性決策、有限理性（賽蒙）、滿意解
- [ ] 直覺決策、實證管理
- [ ] 問題類型與決策類型：結構化／程式化、非結構化／非程式化
- [ ] 決策情境：確定、風險（期望值）、不確定（大中取大、小中取大、大中取小後悔）
- [ ] 決策風格；常見偏誤（過度自信、錨定、確認、沉沒成本、代表性、框架）
- [ ] 群體決策：優缺點、腦力激盪、名目群體、德爾菲法、電子會議
- [ ] 群體迷思、群體偏移、風險移轉

## 六、規劃

- [ ] 規劃的目的與缺點；目標的種類（策略／財務、正式／實際）
- [ ] 目標設定：傳統由上而下 vs. 目標管理 MBO（步驟、優缺點）
- [ ] 好目標的特性 SMART
- [ ] 計畫的分類：廣度（策略／作業）、時間（長／短）、明確性（方向／特定）、頻率（單一／常備）
- [ ] 規劃的權變因素：組織層級、環境不確定性、承諾概念
- [ ] 規劃技術：環境掃描、競爭者情報、預測（量化／質化）、標竿學習
- [ ] 資源分配：預算、排程（甘特圖、負荷圖、PERT 計畫評核術、要徑）
- [ ] 損益兩平分析、線性規劃、情境規劃

## 七、策略管理

- [ ] 策略管理六步驟；使命、願景、目標
- [ ] SWOT：內部優劣勢（資源、能力、核心競爭力）＋外部機會威脅
- [ ] 公司層級策略：成長（集中、垂直整合、水平整合、多角化）、穩定、更新（緊縮、轉型）
- [ ] BCG 矩陣：明星、金牛、問題、狗
- [ ] 安索夫產品／市場矩陣：市場滲透、市場開發、產品開發、多角化
- [ ] 事業層級策略：波特三種一般性策略（成本領導、差異化、集中）、卡在中間
- [ ] 波特五力分析
- [ ] 功能層級策略；策略性彈性、第一進入者優勢
- [ ] 藍海策略、平衡計分卡（財務、顧客、內部流程、學習成長）
- [ ] 價值鏈（波特）

## 八、組織結構與設計

- [ ] 組織設計六要素：工作專業化、部門化、指揮鏈、控制幅度、集權／分權、正式化
- [ ] 部門化方式：功能、產品、地區、顧客、程序
- [ ] 指揮鏈：職權、職責、統一指揮；直線職權、幕僚職權、功能職權
- [ ] 機械式 vs. 有機式組織；影響結構的因素（策略、規模、技術、環境）
- [ ] 伍華德技術分類：單位小量、大量、連續程序
- [ ] 傳統結構：簡單、功能、事業部
- [ ] 當代結構：團隊、矩陣（雙重指揮）、專案、無疆界、虛擬、網路
- [ ] 學習型組織、扁平化、精簡
- [ ] 組織圖能看出：管理層級、指揮鏈、任務、分工

## 九、人力資源管理

- [ ] 人資流程：規劃 → 招募／解雇 → 甄選 → 導引 → 訓練 → 績效 → 薪酬 → 生涯
- [ ] 工作分析、工作說明書、工作規範
- [ ] 招募來源；甄選工具（申請表、測驗、面談、實際工作預覽）；信度、效度
- [ ] 訓練方法：在職、職外；工作輪調、工作擴大化、工作豐富化
- [ ] 績效評估方法：書面評語、關鍵事件、評等尺度、行為定錨、多人比較、360 度、MBO
- [ ] 薪酬：技能基準薪、變動薪、影響因素
- [ ] 當代議題：精簡、性騷擾、職家平衡、多元化
- [ ] 工會、勞資關係基本概念〔B〕

## 十、變革與創新

- [ ] 變革的力量：外部（市場、法規、科技、經濟）、內部（策略、人力、設備、態度）
- [ ] 平靜水域（李文三步驟：解凍、變革、再凍結）vs. 急流泛舟
- [ ] 變革類型：結構、技術、人員；組織發展 OD 技術（敏感度訓練、調查回饋、團隊建立）
- [ ] 抗拒變革的原因與克服方法（教育溝通、參與、協助、協商、操縱、強制）
- [ ] 壓力：來源、症狀、管理
- [ ] 創造力 vs. 創新；激發創新的變數（結構、文化、人資）；點子鬥士
- [ ] 破壞式創新（克里斯汀生）、設計思考

## 十一、個體行為

- [ ] 組織行為的目標：解釋、預測、影響；冰山比喻
- [ ] 態度三成分：認知、情感、行為；工作滿足、投入、承諾、組織公民行為
- [ ] 認知失調（費斯汀格）
- [ ] 人格：MBTI、五大人格；情緒智商、內外控、馬基維利、自尊、自我監控、風險傾向、A／B 型
- [ ] 知覺：歸因理論（內／外歸因、基本歸因誤差、自利偏差）、捷徑（選擇性、假設相似、刻板、月暈）
- [ ] 學習：操作制約（正增強、負增強、懲罰、消弱）、社會學習、行為塑造

## 十二、群體與團隊

- [ ] 群體發展五階段：形成、風暴、規範、執行、解散
- [ ] 群體結構：角色、規範、順從（艾許實驗）、地位、規模、凝聚力
- [ ] 社會賦閒；群體決策優缺點
- [ ] 衝突觀點：傳統、人群關係、互動；功能性 vs. 失能衝突；任務／關係／程序衝突
- [ ] 衝突處理五法：迴避、順應、強迫、妥協、合作
- [ ] 團隊類型：問題解決、自我管理、跨功能、虛擬
- [ ] 高效團隊特徵；團隊 vs. 群體的差別

## 十三、激勵

- [ ] 激勵的定義與三要素：強度、方向、持續
- [ ] 早期理論：馬斯洛需求層級、麥克葛羅格 X／Y 理論、赫茲伯格雙因子、麥克里蘭三需求（成就、權力、親和）
- [ ] 當代理論：目標設定、增強、工作設計（工作特性模式 JCM 五核心構面）、公平理論、期望理論（期望 × 工具 × 價值）
- [ ] 阿特福 ERG 理論；認知評價理論
- [ ] 激勵實務：彈性工時、工作分享、遠距、變動薪、員工認股、開卷管理
- [ ] 激勵不同族群：多元員工、專業人員、臨時工、低技能員工

## 十四、領導

- [ ] 領導者 vs. 管理者；特質論
- [ ] 行為論：愛荷華（獨裁、民主、放任）、俄亥俄州（體制、關懷）、密西根（員工導向、生產導向）、管理方格（布雷克與莫頓）
- [ ] 權變論：費德勒模式（LPC）、赫塞—布蘭查情境領導（告知、推銷、參與、授權）、路徑—目標理論（豪斯）、領導者參與模式
- [ ] 當代觀點：交易型 vs. 轉換型、魅力型、願景型、團隊領導
- [ ] 領導者權力來源（傅蘭琪與雷芬）：法職、獎賞、強制、專家、參照
- [ ] 信任的五構面；授權；領導替代物
- [ ] 李克特四系統；坦南邦—史密特領導連續帶

## 十五、溝通

- [ ] 溝通程序七要素：發訊者、編碼、訊息、通路、解碼、收訊者、回饋；噪音
- [ ] 人際溝通方法與選擇準則；非語言溝通、肢體語言
- [ ] 溝通障礙：過濾、選擇性知覺、資訊過荷、情緒、語言、性別、國家文化
- [ ] 克服障礙：回饋、簡化語言、主動傾聽、控制情緒、注意非語言
- [ ] 組織溝通：正式／非正式、方向（向下、向上、橫向、斜向）、網路（鏈狀、輪狀、全通路）
- [ ] 葡萄藤；資訊科技對溝通的影響；知識管理

## 十六、控制

- [ ] 控制的定義與重要性；控制程序三步驟：衡量、比較、行動
- [ ] 衡量來源：親自觀察、統計報告、口頭、書面
- [ ] 可接受的變異範圍；矯正行動（立即／根本）、修正標準
- [ ] 控制類型：事前（前饋）、事中（同步）、事後（回饋）
- [ ] 控制範圍：財務（比率分析：流動性、槓桿、活動、獲利）、預算、資訊、平衡計分卡、標竿
- [ ] 組織績效衡量：生產力、效能、產業排名
- [ ] 當代議題：跨文化、職場隱私、員工竊盜、暴力、公司治理

## 十七、作業與價值鏈管理

- [ ] 作業管理：投入 → 轉換 → 產出；製造業 vs. 服務業
- [ ] 價值鏈管理的目標、需求（協調、技術投資、程序、領導、員工、文化）
- [ ] 品質：TQM、ISO 9000、六標準差、品管圈
- [ ] 大量客製化、精實生產、豐田生產系統（JIT、看板、自働化）
- [ ] 存貨管理：經濟訂購量 EOQ、ABC 分類、安全存量
- [ ] 產能、廠址、佈置（程序、產品、固定位置）
- [ ] 供應鏈管理、外包、專案管理

## 十八、企業機能：行銷〔企業概論〕

- [ ] 行銷觀念演進：生產、產品、銷售、行銷、社會行銷
- [ ] STP：市場區隔（地理、人口、心理、行為變數）、目標市場選擇、定位
- [ ] 行銷組合 4P：產品、價格、通路、推廣；服務業 7P
- [ ] 產品層次、產品分類、產品生命週期（導入、成長、成熟、衰退）與各期策略
- [ ] 服務四特性：無形性、不可分離性、易變性、易逝性
- [ ] 定價方法：成本加成、目標報酬、認知價值、競爭；新產品定價（吸脂、滲透）
- [ ] 通路長度、密集／選擇／獨家配銷；推廣組合（廣告、促銷、公關、人員銷售、直效）
- [ ] 消費者購買決策過程；品牌、品牌權益；行銷研究

## 十九、企業機能：財務與會計〔企業概論〕

- [ ] 四大財務報表：資產負債表、綜合損益表、現金流量表、權益變動表
- [ ] 會計恆等式；流動 vs. 非流動；折舊
- [ ] 財務比率：流動比率、速動比率、負債比率、存貨週轉、ROA、ROE、EPS、本益比
- [ ] 資金來源：短期（商業信用、銀行借款、商業本票）、長期（股票、債券、保留盈餘）
- [ ] 貨幣時間價值、淨現值 NPV、內部報酬率 IRR、回收期間
- [ ] 風險與報酬、風險溢酬、投資組合分散
- [ ] 資本結構、財務槓桿、股利政策

## 二十、企業機能：資訊、電子商務與創業〔企業概論〕

- [ ] 資訊系統類型：交易處理、管理資訊、決策支援、主管資訊、專家系統、ERP、CRM、SCM
- [ ] 電子商務模式：B2B、B2C、C2C、O2O；平台經濟、長尾
- [ ] 大數據、人工智慧、雲端對企業的影響
- [ ] 企業型態：獨資、合夥、公司（有限、股份有限）；中小企業定義
- [ ] 創業程序、商業模式九宮格、加盟
- [ ] 企業成長階段與生命週期
