設定：連到你的 GitHub

這把「鑰匙」（token）讓網站能直接把筆記寫回 repo，不用再跳去 GitHub。它只存在這台瀏覽器裡。
  1. 到 GitHub → 產生 Fine-grained token
  2. Token name 打 daybook；Expiration 選最長的 1 year（或 Custom）
  3. Repository access 選 Only select repositories → 勾
  4. Permissions → Repository permissions → Contents 改成 Read and write（其他都不用動）
  5. 按 Generate token，把 github_pat_… 整串複製，貼到下面
